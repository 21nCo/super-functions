# LangFn

The `langfn` TypeScript package provides model calls, prompts, structured output, tools, chains, state graphs, agents, memory, RAG, observability, evaluation, HTTP routes, and MCP adapters. Start with [getting started](/docs/getting-started) and use the [provider matrix](/docs/reference/compatibility) when choosing a model.

This site describes the current `origin/dev` TypeScript source, an unpublished adoption targeting package version `0.1.0`. The root LangFn README still lists Python and `@langfn/admin`, but neither package is present in this checkout. Its linked `SPEC.md` is also absent. Do not infer those surfaces from the root README or assume a same-version registry artifact includes these dev changes. Verify the actual installed artifact before adoption.
