Sendfn is a complete platform for all communications that can be self-deployed similar to other superfunctions.

In this v0

`sendfn` SDK
- Basic email sending and receiving
- Transactional email templates (within codebase for now - later file storage and admin dashboard)
- AWS SES provider adapter (interface and other adapters can be added later)
- Suppression list for bounces, complaints, unsubscribe
- Base event tracking 
 - Events available via AWS SES (like bounce, complaint, delivery, etc)
- Basic push notification support (using FCM for Android, APNS for iOS)
- Storing device tokens, email transactions, suppression lists etc are all handled by SendFn - with the provided database adapter


```example_consumer.ts
import { sendfn } from "sendfn";
import { DrizzleAdapter } from '@superfunctions/db/adapters'

const database = new DrizzleAdapter({ /* config */ });

const sendfnClient = sendfn({
database: 
  provider: "aws-ses",
  fromEmail: "someemail@some.com",
  awsSesConfig: {
    accessKeyId: process.env.AWS_SES_ACCESS_KEY_ID!,
    secretAccessKey: process.env.AWS_SES_SECRET_ACCESS_KEY!,
    region: process.env.AWS_SES_REGION!,
  },
  //Other configuration for push notifications
});

// Usage example - sending a transactional email
async function sendWelcomeEmail(userId: string, to: string, userName: string) {
  await sendfnClient.email({
    userId,
    to,
    templateId: "welcome-email",
    templateData: {
      userName,
    },
  })
}

//Usage example - sending a push notification
async function sendPushNotification(userId: string, title: string, body: string) {
  await sendfnClient.push({
    userId,
    title,
    body,
  });
}

//Other methods


```
