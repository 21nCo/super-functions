---
title: SendFn
description: Self-hosted communications with provider adapters and persistence.
---

SendFn provides product communications through TypeScript and Python SDKs. The TypeScript package supports email, SMS, WhatsApp, and push with injected providers, a database adapter, transaction and event records, and an optional HTTP router. The Python package has its own version and feature surface.

Start with [getting started](/docs/getting-started), then choose [channels](/docs/channels) and [providers](/docs/providers). Read the [TypeScript](/docs/reference/typescript) or [Python](/docs/reference/python) source guide for exact APIs.
