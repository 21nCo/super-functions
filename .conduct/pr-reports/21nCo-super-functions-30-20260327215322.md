## 🔴 Critical Issues (2 Total)

### packages/http/src/cookies.ts - Cookie header construction
**📁 File:** `packages/http/src/cookies.ts`

#### Issue 1: `serializeSetCookie` accepts unsafe header fields *(sourcery-ai[bot], qodo-code-review[bot])*
- **Severity:** High
- **Description:** The serializer only checks for an empty cookie name and then interpolates `name`, `path`, and `domain` directly into the `Set-Cookie` string. Reviewers flagged malformed-cookie and header-injection risk from CR/LF and delimiter characters.
- **Location:** Lines 71-83
- **Fix:** Validate cookie names against a conservative token pattern and reject CR/LF/NUL/`;` in all non-encoded header attributes before joining the header.

#### Issue 2: Runtime validator allows `auth` metadata without required `mode` *(chatgpt-codex-connector[bot], greptile-apps[bot], cubic-dev-ai[bot])*
- **Severity:** High
- **Description:** `assertValidRouteMeta` asserts `HttpRouteMeta`, but it accepts `{ auth: {} }` even though `AuthRouteMeta.mode` is required by the type definition.
- **Location:** Around lines 122-125
- **Fix:** Enforce presence of `auth.mode` whenever `auth` metadata is provided, or relax the type so runtime and compile-time behavior match.

## 🟡 Medium Severity Issues (4 Total)

### packages/http/src/cookies.ts - Cookie behavior and runtime typing
**📁 File:** `packages/http/src/cookies.ts`

#### Issue 1: Parsed cookies should not be stored in a prototype-bearing object *(chatgpt-codex-connector[bot])*
- **Severity:** Medium
- **Description:** `parseCookieHeader` writes untrusted cookie names into a plain `{}` object, which can mishandle keys like `__proto__` and create prototype-related surprises.
- **Location:** Line 33
- **Fix:** Use `Object.create(null)` or `Map` for the parsed cookie container.

#### Issue 2: `SameSite=None` is allowed without `Secure` *(greptile-apps[bot], cubic-dev-ai[bot])*
- **Severity:** Medium
- **Description:** Browsers reject `SameSite=None` cookies unless they also carry the `Secure` attribute, but the serializer currently permits `secure: false`.
- **Location:** Around line 93
- **Fix:** Enforce `Secure` when `sameSite` is `none`, or reject the combination explicitly.

#### Issue 3: Auth metadata validation is incomplete for `csrf` and `scopes` *(coderabbitai[bot])*
- **Severity:** Medium
- **Description:** Review feedback noted that the runtime validator checks `auth.mode` but does not validate the declared shapes of `auth.csrf` and `auth.scopes`.
- **Location:** Around lines 113-131
- **Fix:** Validate `csrf` as a boolean and `scopes` as a string array when either field is present.

### packages/http/src/__tests__/cookies.test.ts - Error and edge-case coverage
