## Don't see your stack?

If your backend can speak HTTP, DataFn works. The TypeScript routes are just async functions returning a JSON envelope; you can wire them into any router (Fastify, Koa, h3, AWS Lambda, Vercel, Cloudflare Workers). See [Routes](/docs/reference/routes) for the raw contract.

For client frameworks (React, Vue, Solid), wrap a `createDatafnClient(...)` in your usual state library — `client.table("tasks").signal(...)` returns a subscribable value that fits any reactive system.
