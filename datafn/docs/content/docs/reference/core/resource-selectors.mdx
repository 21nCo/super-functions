---
title: "Resource Selectors"
description: "Parse DataFn request envelopes and collect structural resource selectors."
audience: reference
applies_to: typescript
---

Canonical protocol helpers exported by `@datafn/core` and re-exported by `@datafn/server`. See [Structural resource selectors](/docs/documentation/security/resource-selectors) for gateway and authorization guidance.

```typescript
const DATAFN_REQUEST_PROTOCOL_VERSION = "1";

type DatafnRequestAction =
  | "status"
  | "query"
  | "mutation"
  | "transact"
  | "search"
  | "seed"
  | "clone"
  | "pull"
  | "push"
  | "reconcile";

type DatafnResourceSelector = string & {
  readonly __brand: "DatafnResourceSelector";
};

type StructuralResourceSelection = {
  readonly selectors: readonly DatafnResourceSelector[];
  readonly protocolVersion: "1";
};

function parseDatafnRequest(
  action: string,
  payload: unknown,
): DatafnEnvelope<ParsedDatafnRequest>;

function collectStructuralResourceSelectors(
  request: ParsedDatafnRequest,
): StructuralResourceSelection;

function extractStructuralResourceSelectors(
  action: string,
  payload: unknown,
): DatafnEnvelope<StructuralResourceSelection>;
```

`parseDatafnRequest` validates protocol envelope shape and selector-field types. It does not traverse application records or filter operands. `collectStructuralResourceSelectors` is exhaustive over `ParsedDatafnRequest`.
