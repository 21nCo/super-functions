## How to use a recipe

1. Read the recipe end to end before copying.
2. Adapt the schema to your domain. Capabilities (`timestamps`, `audit`, `trash`, etc.) are the levers; pick the ones you need.
3. Mount the routes on the framework you actually use. The recipes lean on Hono in examples, but the pattern is the same for any framework — see the [Quickstart](/docs/quickstart) section.
4. Steal whatever you need from the client glue, then delete the rest.
