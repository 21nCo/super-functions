# Quickstart

If you want a guided walk through every concept, follow [Getting Started](../getting-started). The pages below are stack-specific recipes — pick yours and copy.

| Stack | Walkthrough |
| --- | --- |
| Node + Hono / Express | [Node.js quickstart](./nodejs) |
| Bun | [Bun quickstart](./bun) |
| SvelteKit | [SvelteKit quickstart](./sveltekit) |
| Next.js (App Router) | [Next.js quickstart](./nextjs) |
| Python + FastAPI / Flask | [Python quickstart](./python) |
| iOS / macOS Swift | [Swift quickstart](./swift) |

If your framework isn't listed, the on-the-wire contract is identical regardless of how you mount authfn. See the [Frameworks](../frameworks) section for adapters in Express, Hono, Bun, SvelteKit, Next.js, FastAPI, Flask, Starlette, and a "bring your own framework" guide if you want to wire authfn to anything that hands you a `Request`.
