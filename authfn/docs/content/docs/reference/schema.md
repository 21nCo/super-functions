# Database schema

The schema is generated by `npx superfunctions auth schema` from your enabled plugin set. Tables are namespaced (`authfn_*` by default) so authfn coexists with the rest of your schema cleanly.

This page describes every table that **could** exist; only tables for enabled plugins are emitted.

## Built-ins

### `authfn_users`

The user record. Stable ids; emails on the user are denormalized for convenience but the source of truth depends on plugin policy.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | text PK | `user_<random>`. |
| `primaryEmail` | text | Optional; set when the user has at least one verified email. |
| `emailVerifiedAt` | timestamp | Set after `verify-email` OTP. |
| `metadata` | json | Free-form; you own this. |
| `createdAt` | timestamp | `now()` at insert. |
| `updatedAt` | timestamp | Touched on update. |

### `authfn_sessions`

A signed session.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | text PK | `session_<random>`. |
| `userId` | text FK → `authfn_users.id` |  |
| `tokenHash` | text | SHA-256 of the raw session token. |
| `csrfHash` | text | SHA-256 of the CSRF token. |
| `methods` | json | `string[]` — `['password']`, `['oauth-google']`, etc. |
| `lastAuthenticatedAt` | timestamp | Last sensitive interaction. |
| `expiresAt` | timestamp | Session expiry. |
| `revokedAt` | timestamp | Set on revoke. |
| `metadata` | json | Free-form. |
| `createdAt` / `updatedAt` | timestamp |  |

## Source of truth

Generated by `@superfunctions/cli` (`superfunctions auth schema`). The CLI walks `auth.config.plugins`, asks each for its `schema()`, and emits idiomatic Drizzle / SQLAlchemy / Prisma definitions.

To regenerate after enabling or removing a plugin:

```bash
npx superfunctions auth schema
```

For the live SQL types, see the generated files in `authfn/examples/*/server/src/db/generated/authfn-schema.ts`.
