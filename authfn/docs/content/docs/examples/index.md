# Examples

The `authfn/examples/` directory in the repo ships **five end-to-end examples**. Each isolates a single capability so the code stays readable and the Playwright suite stays deterministic. Every example uses:

- **Server**: Express + `@superfunctions/http-express` + `@authfn/core` + Postgres via Drizzle.
- **Client**: Svelte 5 + Vite + `@authfn/client` + `@authfn/svelte`.
- **Schema**: generated by `@superfunctions/cli`.
- **Tests**: Playwright, end-to-end.

| Example | Focus |
| --- | --- |
| [password-sessions](./password-sessions) | Email/password sign-up, sign-in, session list / revoke / sign-out. |
| [otp-recovery](./otp-recovery) | Email OTP for verify, sign-in, password reset. |
| [social-oauth](./social-oauth) | OAuth start / callback / disconnect with a local fake provider. |
| [account-settings](./account-settings) | Two-factor enroll/disable + API-key list/create/revoke. |
| [multi-region-routing](./multi-region-routing) | Wrong-authority correction across two regional servers. |

## Shared harness

A small package (`@authfn/examples-shared`) provides:

- `createExampleServer(...)` — wires Express + authfn + an event log + a `/demo/*` testing surface.
- `ExampleEventBuffer` — captures `observability.emit` events for Playwright assertions.
- `ExampleOtpInbox` — captures generated OTPs so tests can read them deterministically.
- `createFakeOAuthProvider(...)` — a local OAuth server that signs JWTs the kernel will accept.
- Stable `data-testid` constants and selector helpers.

The harness is the right starting point if you're authoring a **new** example.

## Running an example

From the repo root:

```bash
docker compose -f authfn/examples/docker-compose.yml up -d   # local Postgres

cd authfn/examples/<example>
export DATABASE_URL=postgres://postgres:postgres@127.0.0.1:5432/authfn_examples
npm install
npm --prefix ./server run db:generate
npm --prefix ./server run db:push
npm run dev:server     # starts Express server
npm run dev:client     # starts Vite client
```

Run the Playwright tests in another terminal:

```bash
npm run test:e2e
```

## Verification matrix

Run all five examples' Playwright suites:

```bash
npm --prefix authfn/examples/password-sessions run test:e2e
npm --prefix authfn/examples/otp-recovery run test:e2e
npm --prefix authfn/examples/social-oauth run test:e2e
npm --prefix authfn/examples/account-settings run test:e2e
npm --prefix authfn/examples/multi-region-routing run test:e2e
```

…and the example contract validators:

```bash
npm --prefix authfn/examples/shared run validate:ui-contract
npm --prefix authfn/examples/shared run validate:no-external-network
```

CI runs all of these on every PR.
