# Password Sessions

Focused `authfn` example for the email/password browser-session lifecycle: sign-up, sign-in, current-session fetch, session listing, single-session revoke, and sign-out.

## URLs

- Client: `http://127.0.0.1:4010`
- Server: `http://127.0.0.1:4310`
- Auth base path: `http://127.0.0.1:4310/auth`

## Local Postgres

Use a local Postgres database, for example:

```bash
export DATABASE_URL=postgres://postgres:postgres@127.0.0.1:5432/authfn_examples
```

The example stores auth tables under the `authfn_password_sessions_*` table family generated by `@superfunctions/cli`.

## Scripts

From this directory:

```bash
npm run dev:server
npm run dev:client
npm --prefix ./server run db:generate
npm --prefix ./server run db:push
npm run test:e2e
```

The root example package exposes `dev:server`, `dev:client`, and `test:e2e`. The nested `server` package exposes `db:generate` and `db:push`.

## What Playwright Covers

- Sign up with email/password and confirm a cookie session exists.
- Create a second session in a second browser context.
- Fetch the current session and list all sessions.
- Revoke the secondary session from the UI.
- Sign out the current session.
- Attempt a wrong-password sign-in and assert the canonical `AUTHFN_INVALID_CREDENTIALS` envelope is rendered.
