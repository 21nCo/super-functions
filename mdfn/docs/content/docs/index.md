# MDFN

MDFN treats Markdown as the durable document boundary. It derives a structured editor model while retaining source spans and raw slices, so unsupported syntax can survive editing. The package graph separates headless parsing and rendering, framework editors, persistence, collaboration, review, and ecosystem bridges.

Start with [getting started](/docs/getting-started) or explore the [package map](/docs/reference). Read [source preservation](/docs/source-preservation) and [rendering safety](/docs/rendering-and-security) before integrating the editor into a content pipeline.
