# `@mdfn/components`

Framework-neutral models for complete authoring chrome: primary, selection,
and floating toolbars; slash commands; link/table/file controls; outline;
diagnostics; comments; suggestions; review state; and audit history. The engine
remains headless; framework packages render these models with UIFn components.

Import `@uifn/components/styles.css` and `@mdfn/components/styles.css` once in applications that use the styled framework components.
