---
title: Python SDK
description: Use the separately versioned Python helpers.
---

The Python package `apifn` (source directory: `apifn/python`) provides Python helpers for OpenAPI generation, diffing, collections, FastAPI, and Flask. It requires Python 3.10 or newer and has its own version lifecycle, separate from the npm packages.

See the [Python source package](https://github.com/21nCo/super-functions/tree/dev/apifn/python) for its current public exports, installation metadata, and examples. The TypeScript CLI and Python helpers can consume the same OpenAPI contract, but do not assume their release versions match.
