# ApiFn

ApiFn is a code-first API toolkit. Generate OpenAPI 3.1 from a `@superfunctions/http` router, then use the spec to validate changes, run portable request collections, mock responses, generate snippets, and render an interactive reference.

Start with [getting started](/docs/getting-started). For exact options and public APIs, use the [package reference](/docs/reference). The [source overview](/docs/reference/overview) also covers CI configuration and ecosystem integrations.
