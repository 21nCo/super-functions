# Interactive reference

`@apifn/react` and `@apifn/svelte` render an endpoint explorer, schema views, a Try-It console, request history, response diff, and optional performance overlays. Load an OpenAPI document from a trusted source and pass the deployment base URL intentionally: Try-It sends real requests.

The Svelte package ships `.svelte` source subpaths; the package root exports types. The DocsFn plugin `@apifn/docsfn` converts an OpenAPI document to DocsFn content entries and has framework-specific renderers. It is optional and separate from this site's guide content.

Read the [React](/docs/reference/react), [Svelte](/docs/reference/svelte), and [DocsFn plugin](/docs/reference/docsfn) package guides for component imports and provider options.
