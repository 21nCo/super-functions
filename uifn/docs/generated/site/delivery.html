Package and source delivery

The stable framework targets are React, Svelte, and Solid. Package mode uses the matching styled package. Source mode uses the signed offline catalog in @uifn/registry and writes managed files into your project.

Package mode

Install the matching package: @uifn/components-react, @uifn/components-svelte, or @uifn/components-solid. Follow the chosen primitive page for its public imports and parts.

Source mode

uifn add button --framework react --cwd . --dry-run --json
uifn add button --framework react --cwd . --json
uifn diff --cwd . --json
uifn update button --cwd . --dry-run --json

Dry run shows the exact plan without writing. Add and update validate signatures, ownership, dependency compatibility, and dirty-file conflicts before an atomic write. Local edits are never silently overwritten.

Consumer lockfiles

Source installs record file hashes and ownership in .uifn/registry.lock. If uifn apply changes package.json in an npm project with package-lock.json, review requiredActions, refresh the lockfile with npm install --package-lock-only --ignore-scripts --lockfile-version=3, review the diff, and then run npm ci. UIFn does not run npm or edit the npm lockfile during its file transaction.

Use the matching primitive page for framework examples and the package or source import target.
