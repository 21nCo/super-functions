---
title: PlugFn
description: A shared integration runtime for provider connections and workflows.
---

PlugFn is a self-hosted integration runtime for provider registration, connection lifecycle, OAuth callbacks, webhook reception, actions, workflows, and sync jobs. It is a server-side substrate shared by applications; `@plugfn/client` is a narrow browser helper for owned routes.

Start with [getting started](/docs/getting-started), then check [provider readiness](/docs/provider-readiness). Read the [security boundaries](/docs/security-boundaries) before exposing routes. The current [release contract](/docs/reference/release-gates) limits production claims by provider and commit.
