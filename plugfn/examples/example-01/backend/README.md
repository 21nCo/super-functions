# example-01 backend

PostgreSQL-backed PlugFn app using Drizzle tables generated by [`@superfunctions/cli`](../../../../packages/cli).

## Database schema

- **PlugFn module**: `src/plugfn.ts` — canonical `createExamplePlug()` factory; `@superfunctions/cli` parses the inner `plugFn({ ... })` call from this file (see `superfunctions.config.mjs`).
- **Generated Drizzle definitions**: `src/db/generated/plugfn-schema.ts` — run `npm run db:generate` after PlugFn storage schema changes in the library.
- **Applying tables**: configure `DATABASE_URL`, then run `npm run db:push` (Drizzle Kit) or manage SQL migrations with your preferred workflow.

## Scripts

| Script                | Purpose                                              |
|-----------------------|------------------------------------------------------|
| `npm run db:generate` | Build plugfn/db/cli packages and regenerate schema.  |
| `npm run db:push`     | Push schema to Postgres (`drizzle-kit push`).        |
| `npm start`           | Run the server with `tsx`.                           |

## Local deps

This package pins monorepo packages with `file:` links (`plugfn`, `@plugfn/providers`, `@superfunctions/db`, `@superfunctions/cli`). From this directory:

```bash
npm install
```
