title: Autocomplete
description: Search-as-you-type with prefix matching and low latency.
---

The right tool for autocomplete is **prefix matching**, not fuzzy matching. Prefix matches are exact, fast, and predictable. Fuzzy is for typo correction on a final query, not for live-as-you-type.

## Enable edge n-grams

```typescript
import { createMemorySearchClient } from "@searchfn/client";

const client = createMemorySearchClient({
  adapterConfig: {
    pipeline: {
      edgeNgrams: { min: 2, max: 12 },
      indexStages: ["tokenize", "normalize", "edgeNgrams"],
      queryStages: ["tokenize", "normalize"], // exact match against prefix tokens
    },
  },
  defaults: { limit: 10, prefix: true },
});

await client.initialize?.({
  resources: [{ name: "items", searchFields: ["name"] }],
});
```

`indexStages` includes `edgeNgrams`; `queryStages` doesn't. This means indexing `searchfn` produces tokens for `se`, `sea`, ... `searchfn`, but the query `sea` matches as-is.

## Debounce the input

```typescript
import { useState, useEffect } from "react";

function Autocomplete() {
  const [q, setQ] = useState("");
  const [results, setResults] = useState<string[]>([]);

  useEffect(() => {
    if (!q) return setResults([]);
    const ctrl = new AbortController();
    const timer = setTimeout(async () => {
      const ids = await client.search({
        resource: "items",
        query: q,
        limit: 8,
        signal: ctrl.signal,
      });
      setResults(ids as string[]);
    }, 80);
    return () => {
      clearTimeout(timer);
      ctrl.abort();
    };
  }, [q]);

  return (
    <>
      <input value={q} onChange={(e) => setQ(e.target.value)} />
      <ul>{results.map((id) => <li key={id}>{id}</li>)}</ul>
    </>
  );
}
```

Key choices:

- **80 ms debounce** — enough to avoid a request per keystroke; tight enough to feel instant.
- **AbortController** — cancels stale requests; the engine sees `DFQL_ABORTED` and stops.
- **Result limit 8** — autocomplete UIs rarely benefit from more.

## What about typos?

Allow exact prefix matching to handle 95% of cases; expose a "Did you mean?" suggestion using a fuzzy fallback only when prefix returns zero results:

```typescript
let ids = await client.search({ resource: "items", query: q });
if (ids.length === 0 && q.length >= 4) {
  ids = await client.search({ resource: "items", query: q, fuzzy: 1 });
}
```

## Field boosts

Autocomplete usually wants `name` matches above `description` matches:

```typescript
await client.search({
  resource: "items",
  query: q,
  fieldBoosts: { name: 3.0, description: 1.0 },
});
```
