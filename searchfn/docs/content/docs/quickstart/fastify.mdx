title: Fastify
description: SearchFn on Fastify with a single route registration.
---

## 1. Install

```bash
npm install fastify @superfunctions/http-fastify @searchfn/server @searchfn/adapter-memory
```

## 2. Register the route

```typescript
import Fastify from "fastify";
import { toFastify } from "@superfunctions/http-fastify";
import { createSearchFnServer } from "@searchfn/server";
import { MemoryAdapter } from "@searchfn/adapter-memory";

const adapter = new MemoryAdapter();
const sf = await createSearchFnServer({
  adapter,
  basePath: "/searchfn",
});

await adapter.initialize({
  resources: [{ name: "books", searchFields: ["title", "author"] }],
});

const app = Fastify({ bodyLimit: 2 * 1024 * 1024 });

await app.register(toFastify(sf.router));

await app.listen({ port: 3000 });
```

## 3. Smoke test

```bash
curl -X POST http://localhost:3000/searchfn/index \
  -H 'content-type: application/json' \
  -d '{ "resource": "books", "documents": [{ "id": "b-1", "fields": { "title": "Gödel Escher Bach", "author": "Hofstadter" } }] }'

curl -X POST http://localhost:3000/searchfn/search \
  -H 'content-type: application/json' \
  -d '{ "resource": "books", "query": "godel" }'
```

Fuzzy matching is on by default — the typo-corrected hit comes back.
