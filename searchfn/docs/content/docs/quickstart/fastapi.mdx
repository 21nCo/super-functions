---
title: FastAPI
description: Mount Python SearchFn handlers in a FastAPI application.
---

```sh
pip install searchfn fastapi uvicorn
```

Provide `schema` and a compatible async `db` from your application. The adapter needs `find_many`, `create`, and `delete`. Route keys include the HTTP method, and handlers accept `(ctx, payload)`:

```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
from searchfn import create_searchfn_server
from myapp.storage import schema, db

app = FastAPI()
plugin = create_searchfn_server({"schema": schema, "db": db})

def make_endpoint(handler):
    async def endpoint(request: Request):
        try:
            payload = await request.json()
        except ValueError:
            return JSONResponse({"ok": False, "error": "Expected a JSON object"}, status_code=400)
        if not isinstance(payload, dict):
            return JSONResponse({"ok": False, "error": "Expected a JSON object"}, status_code=400)
        result = await handler(None, payload)
        return JSONResponse(result, status_code=200 if result.get("ok") else 400)

    return endpoint


for spec, handler in plugin["routes"].items():
    method, path = spec.split(" ", 1)
    app.add_api_route(path, make_endpoint(handler), methods=[method])
```

Run `uvicorn myapp.app:app` (adjust to your module), then POST JSON to `/searchfn/index` or `/searchfn/search`. Protect index rebuilding with operator authorization and apply your normal request authentication to search.

The host must provision `<table_prefix>index` (default `_searchfn_index`) and authorize both routes. `searchfn` does not import DataFn or set up database tables. For a standalone adapter example, see the [Python source README](https://github.com/21nCo/super-functions/blob/dev/searchfn/python/README.md).

See [Python setup](/docs/documentation/python/setup) and [HTTP mount](/docs/documentation/python/http-mount).
