title: Flask
description: Bridge async Python SearchFn handlers into Flask.
---

```sh
pip install searchfn flask
```

```python
import asyncio
from flask import Flask, jsonify, request
from searchfn import create_searchfn_server
from myapp.storage import schema, db

app = Flask(__name__)
plugin = create_searchfn_server({"schema": schema, "db": db})

def wrap(handler):
    def view():
        result = asyncio.run(handler(None, request.get_json(silent=True) or {}))
        return jsonify(result), (200 if result.get("ok") else 400)
    return view

for spec, handler in plugin["routes"].items():
    method, path = spec.split(" ", 1)
    app.add_url_rule(path, endpoint=f"searchfn_{path.rsplit('/', 1)[-1]}", view_func=wrap(handler), methods=[method])
```

For a synchronous Flask host, the wrapper runs each async handler in its own event loop. Check whether your database adapter supports that lifecycle; an async-native framework may fit better for a high-throughput service. Authenticate search requests and restrict indexing to operators.

The host must provision `<table_prefix>index` (default `_searchfn_index`) and authorize both routes. `searchfn` does not import DataFn or set up database tables. For a standalone adapter example, see the [Python source README](https://github.com/21nCo/super-functions/blob/dev/searchfn/python/README.md).
