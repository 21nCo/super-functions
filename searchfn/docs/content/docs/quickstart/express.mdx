---
title: Express
description: Mount SearchFn into an Express app in under 10 minutes.
---

## 1. Install

```bash
npm install express @superfunctions/http-express @searchfn/server @searchfn/adapter-memory
```

## 2. Mount

```typescript
import express from "express";
import { toExpress } from "@superfunctions/http-express";
import { createSearchFnServer } from "@searchfn/server";
import { MemoryAdapter } from "@searchfn/adapter-memory";

const adapter = new MemoryAdapter();
const sf = await createSearchFnServer({
  adapter,
  basePath: "/searchfn",
});

await adapter.initialize({
  resources: [{ name: "products", searchFields: ["name", "description"] }],
});

const app = express();
app.use(express.raw({ type: "*/*", limit: "2mb" }));
app.use(toExpress(sf.router));

app.listen(3000);
```

## 3. Index + search

```bash
curl -X POST http://localhost:3000/searchfn/index \
  -H 'content-type: application/json' \
  -d '{ "resource": "products", "documents": [{ "id": "p-1", "fields": { "name": "Notebook", "description": "Black A5" } }] }'

curl -X POST http://localhost:3000/searchfn/search \
  -H 'content-type: application/json' \
  -d '{ "resource": "products", "query": "notebook" }'
```

## Production

Use `@searchfn/adapter-postgres` for persistence, set `authorize` to gate writes to admin/service principals, and add an `express.raw({ type: "*/*", limit })` matching the server's `maxPayloadBytes`.
