title: Express
description: Mount SearchFn into an Express app in under 10 minutes.
---

## 1. Install

```bash
npm install express @searchfn/server @searchfn/adapter-memory
```

## 2. Mount

```typescript
import express from "express";
import { createSearchFnServer } from "@searchfn/server";
import { MemoryAdapter } from "@searchfn/adapter-memory";

const sf = await createSearchFnServer({
  adapter: new MemoryAdapter(),
  basePath: "/searchfn",
});

await sf.adapter.initialize?.({
  resources: [{ name: "products", searchFields: ["name", "description"] }],
});

const app = express();
app.use(express.json({ limit: "2mb" }));

app.all("/searchfn/*", async (req, res) => {
  const response = await sf.router.handle({
    method: req.method,
    url: req.originalUrl,
    headers: new Headers(req.headers as Record<string, string>),
    body: JSON.stringify(req.body),
  });
  res.status(response.status);
  response.headers.forEach((v, k) => res.setHeader(k, v));
  res.send(await response.text());
});

app.listen(3000);
```

## 3. Index + search

```bash
curl -X POST http://localhost:3000/searchfn/index \
  -H 'content-type: application/json' \
  -d '{ "resource": "products", "documents": [{ "id": "p-1", "fields": { "name": "Notebook", "description": "Black A5" } }] }'

curl -X POST http://localhost:3000/searchfn/search \
  -H 'content-type: application/json' \
  -d '{ "resource": "products", "query": "notebook" }'
```

## Production

Use `@searchfn/adapter-postgres` for persistence, set `authorize` to gate writes to admin/service principals, and add an `express.json({ limit })` matching the server's `maxPayloadBytes`.
