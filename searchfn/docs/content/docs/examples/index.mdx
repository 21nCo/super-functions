The repo ships a small set of examples that compile against the published packages. Use them as runnable starting points.

## Swift examples (shipped in the Swift package)

| Example | What it shows |
| --- | --- |
| [In-memory](/docs/examples/swift-in-memory) | `MemoryAdapter`, index, search, searchAll, remove, clear |
| [SQLite](/docs/examples/swift-sqlite) | `SQLiteAdapter`, persistence, re-open with `indexKey` |

Both ship as Swift package executables. Run them from the repo root:

```bash
swift run --package-path searchfn/swift SearchFnInMemoryExample
swift run --package-path searchfn/swift SearchFnSQLiteExample
```
