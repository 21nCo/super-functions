SearchFn ships a coordinated set of packages. Each release notes which packages changed.

## 0.2.0 — 2026-03-11

### Breaking

- Removed the legacy aggregate adapters package.
- Split adapters into dedicated packages:
  - `@searchfn/adapter-contracts`
  - `@searchfn/adapter-memory`
  - `@searchfn/adapter-indexeddb`
  - `@searchfn/adapter-postgres`
  - `@searchfn/adapter-meilisearch`
  - `@searchfn/adapter-elasticsearch`
  - `@searchfn/adapter-opensearch`

## Versioning policy

- **Patch (0.x.y)**: bug fixes, doc improvements, perf wins that don't change behavior.
- **Minor (0.x.0)**: new features, new adapters, backwards-compatible additions to the SearchAdapter contract.
- **Major (x.0.0)**: contract changes, removed deprecated APIs, breaking changes to envelopes.

SearchFn is in 0.x — minor versions may include breaking changes when called out in this changelog.

## Coordinated releases

`@searchfn/*` packages share a version. Upgrading is per-package, but the same version across packages is the supported configuration. Mixing major versions across packages is not supported.

## Upgrade guides

- Major bumps include a `### Migration` section above with package/import/dependency mappings.
- Run `npm ls @searchfn/*` after an upgrade to confirm versions match across the tree.
