The Python `searchfn` kernel requires Python 3.9 or newer and has no required DataFn dependency. Any async adapter with `find_many`, `create`, and `delete` can back the index. A DataFn adapter is compatible when it offers those methods.

```python
from searchfn import create_searchfn_server, index_data, search_index

plugin = create_searchfn_server({
    "schema": schema,          # resources or models; mapping or named list
    "db": db,                  # duck-typed async adapter
    "table_prefix": "_searchfn_",  # optional
})
```

`create_searchfn_server` returns `{"routes": {"POST /searchfn/index": handler, "POST /searchfn/search": handler}}`. Each handler is async and accepts `(ctx, payload)`. The index handler accepts optional `model` and returns `{"ok": True, "result": {"totalIndexed": int, "totalTerms": int}}`. The search handler requires a non-empty `query`, accepts optional `model` and positive `limit` up to 10,000, and returns `{"ok": True, "results": [...]}`.

`index_data(schema, db, model=None, table_prefix="_searchfn_")` scans string fields and replaces term rows for each source record. `search_index(schema, db, query, model=None, limit=20, table_prefix="_searchfn_")` ranks by matching index-row count. Hits contain `id`, `model`, `score`, and sorted `matches`. Ties sort by model and record ID. The host provisions the `<table_prefix>index` table, authorizes routes, and decides when to reindex.

Read [setup](/docs/documentation/python/setup), [indexing](/docs/documentation/python/indexing), [search](/docs/documentation/python/search), and [HTTP mount](/docs/documentation/python/http-mount) for integration details. The [source README](https://github.com/21nCo/super-functions/blob/dev/searchfn/python/README.md) includes a minimal adapter example.
