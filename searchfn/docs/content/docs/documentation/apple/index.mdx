The Swift package is a standalone search runtime. It ships:

- `SearchFnCore` — the BM25 engine, ported to Swift.
- `SearchFnMemoryAdapter` — in-memory adapter.
- `SearchFnSQLiteAdapter` — SQLite-backed persistent adapter.
- `SearchFnClient` — validating client facade.
- `SearchFnConvenience` — one-liner constructors.

It does **not** depend on DataFn or the TypeScript server. You can use it standalone, or pair it with DataFn's Apple runtime via the WebView bridge.

## When to use which adapter

| Use case | Adapter |
| --- | --- |
| Tests / CLI tools | `SearchFnMemoryAdapter` |
| App with persistent search | `SearchFnSQLiteAdapter` |
| App embedded in a WebView with DataFn | `SearchFnSQLiteAdapter` under the DataFn Apple runtime |
