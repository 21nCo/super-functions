The Python `searchfn` package is an independent, dependency-free inverted-index kernel. It accepts a schema and any async database adapter with `find_many`, `create`, and `delete`. DataFn is one compatible host; it is not required to import or install this package. The package requires Python 3.9 or newer and does not provide the TypeScript engine's BM25 or adapter set.

| Surface | Purpose |
| --- | --- |
| `create_searchfn_server` | Return async index and search handlers for a host HTTP framework. |
| `index_data` | Scan declared string fields and write term rows. |
| `search_index` | Look up matching term rows and rank results. |

The host must provision the `<table_prefix>index` table and authorize the HTTP routes. The default name is `_searchfn_index`. SearchFn does not create database tables or authenticate requests. See [setup](/docs/documentation/python/setup), [indexing](/docs/documentation/python/indexing), [search](/docs/documentation/python/search), and [HTTP mount](/docs/documentation/python/http-mount).
