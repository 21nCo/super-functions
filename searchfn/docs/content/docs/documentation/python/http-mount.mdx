title: HTTP mount
description: Wrap Python SearchFn's route map with your framework and auth policy.
---

`create_searchfn_server({"schema": schema, "db": db})` returns a `routes` mapping with keys `POST /searchfn/index` and `POST /searchfn/search`. Each value is an async handler called as `await handler(ctx, payload)`. The current handlers do not use `ctx`; `payload` is the parsed JSON body. Split each route key into method and path before registering it in your framework.

```python
plugin = create_searchfn_server({"schema": schema, "db": db})
for spec, handler in plugin["routes"].items():
    method, path = spec.split(" ", 1)
    # Register path with method. In your wrapper, call await handler(None, parsed_json).
```

The handler returns an envelope with `ok`. Translate `ok: False` into an appropriate HTTP status, and keep the response body for callers. The handlers do not authenticate, rate-limit, or configure CORS. Gate indexing behind an operator permission and apply a read policy to search. Framework examples: [FastAPI](/docs/quickstart/fastapi), [Starlette](/docs/quickstart/starlette), and [Flask](/docs/quickstart/flask).

The host must provision the index table; see [setup](/docs/documentation/python/setup). The [source README](https://github.com/21nCo/super-functions/blob/dev/searchfn/python/README.md) includes a minimal adapter example.
