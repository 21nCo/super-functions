# Claude

Download [`llms.txt`](/docs/llms.txt) or [`llms-full.txt`](/docs/llms-full.txt) and provide the relevant content to Claude. For a project, a short `CLAUDE.md` can point to the docs and the packages in use:

```md
# FileFn

This project uses FileFn for uploads and downloads. Read https://filefn.com/docs/getting-started and the relevant adapter guide before changing its configuration. Check the installed package APIs and run the project tests.
```

The docs site currently has no MCP endpoint to register. See [MCP availability](./mcp).
