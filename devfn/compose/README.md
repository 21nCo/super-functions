# @devfn/compose

Requires Docker Compose 2.24.4 or newer. Starts only declared Compose services with `--no-deps` under a project name whose readable prefix is case folded and whose digest includes the exact prefix and opaque owner bytes; case-distinct prefixes remain separate even if their readable names normalize alike. It replaces source mappings with loopback or explicitly public DevFn host-port mappings while retaining conventional container ports, and never removes persistent volumes during ordinary cleanup. Secret-bearing services disable Docker log persistence.

Ready receipts fingerprint the selected effective Compose service, referenced volume/network/config definitions, and noncredential environment values after Compose interpolation. Default and include-scoped env files participate when they affect that service; overridden inputs and unrelated services do not. Compose source references to inherited host variables such as `HOME` require an explicit `envAllowlist` entry, so ambient values do not silently enter a receipt. Credential-named and `secretEnv` values are redacted before hashing. Source graphs are bounded before Compose reads them for endpoint planning.
