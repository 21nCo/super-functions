# Package reference

These pages incorporate the package documentation from the current `origin/dev` source. Use them for detailed API examples and edge cases after the guides.

- [Core runtime](/docs/reference/core): declarations, registries, profiles, resources, tasks, apps, and error behavior.
- [Client](/docs/reference/client): targets, lifecycle, inventories, events, and OAuth completion.
- [Authorization](/docs/reference/auth): resource server, client provider, hosted authorization, and redirects.
- [Testing API](/docs/reference/testing): test clients, profile contracts, remote suites, and auth fixtures.
- [Inspector](/docs/reference/inspector): headless operations and sanitized scenario export.
- [DataFn adapter](/docs/reference/datafn): allowlisted resource and field exposure.
- [CLI](/docs/reference/cli): command usage and result behavior.
- [Architecture](/docs/reference/architecture) and [testing and CI](/docs/reference/testing-and-ci): design boundaries and release evidence.

The source of truth for a published package's exact exports is its versioned package artifact. These pages describe the code on `origin/dev` at the time this site was prepared.
